# Authorship and third-party materials

The exported implementation, prompts, synthetic fixtures, tests and project
documentation were authored for this project and are released under MIT by
Ye Lei. Their project history and source headers were reviewed for copied code
and attribution notices; no vendored third-party implementation was identified.
This review is based on the available source/provenance, not an assertion about
the ownership of upstream datasets or model outputs.

Python's standard library is used at runtime. Setuptools is a build dependency;
pytest is an optional test dependency. Install these through their normal
distributions under their respective licenses; no dependency source is bundled.

ProofWriter data and Qwen model weights are external resources under their own
terms. The project-generated fixture is synthetic, not a redistributed dataset
split. Test programs and leakage sentinels are synthetic. Aggregate evaluation
counts are project-produced summaries; no model-generated passages or official
gold/reference packets are included.

NeurIPS style/template files, third-party PDFs, the submitted report and all
other files with unclear redistribution rights are excluded. No public PDF is
provided. The historical report has not been relicensed or changed.
